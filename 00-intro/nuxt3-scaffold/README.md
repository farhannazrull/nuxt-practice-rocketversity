# Nuxt 3 Scaffold

Scaffold awal untuk hands-on instalasi Nuxt. Project ini menggunakan JavaScript dan Nuxt versi terbaru dari `create-nuxt`.

## Setup

```bash
npm install
npm run dev -- -o
```

Validasi production build:

```bash
npm run build
```

Halaman utama berisi checklist prerequisites, link online sandbox, dan perintah terminal dari bagian Installation course.
